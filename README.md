# 梗一下

一个在线表情包创作工具，包含四条创作路线：

- 用提示词直接生成表情包，或上传参考图后重画，再继续编辑、复制或制作动态 GIF
- 上传人物照片，可选 2×2、3×3、3×4 或 4×4 规格，由 `gpt-image-2` 一次生成 4、9、12 或 16 张常用表情和匹配中文配字，再由浏览器切成独立图片并下载 PNG、动态 GIF 或无动画静态 GIF 压缩包
- 上传图片，在本地叠加文案、版式与字体
- 在浏览器中把图片或视频片段转换成 GIF

## 本地开发

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

## AI 接口

网页右上角的「AI 设置」支持 OpenAI-compatible 服务：

- `Base URL`：API 根地址，通常以 `/v1` 结尾
- `API Key`：仅保存在当前浏览器会话
- `Image Model Name`：用于提示词生图和参考图编辑

生图服务需要兼容 Images API：纯提示词调用 `/images/generations`，参考图调用 `/images/edits`。站点端也可通过 `OPENAI_API_KEY` 与 `OPENAI_IMAGE_MODEL` 提供默认服务。

提示词会被服务端固定的表情包系统提示词约束，优先生成主体清楚、适合聊天转发的表情包。人物套装中的表情、动作和短中文配字均由 `gpt-image-2` 自适应创作，浏览器不会二次叠字，只负责按所选网格切图、按需制作动态或单帧静态 GIF，并生成压缩包。手动图片编辑与图片/视频转 GIF 完全在浏览器处理；AI 生图的提示词和可选参考图会发送给当前配置的 AI 服务。

GIF 工具支持上传本地视频、粘贴视频直链，以及上传图片、直接粘贴剪贴板图片或使用图片直链。图片可添加抖动、弹跳、缩放或闪烁动效，并设置速度、循环次数和高清/小体积规格。生成后可直接复制或下载；不支持 GIF 剪贴板格式的浏览器会自动提供兼容的 HTML/PNG 内容。远程直链需要来源站点允许浏览器跨域读取（CORS）；若来源禁止跨域，可先下载素材再上传。
